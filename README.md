# gothic-remake-assets

Тайлы подложки и картинки из окон меток для интерактивной карты [Gothic 1 Remake](https://broskiplay.ru/gothic-remake-map/) (BroskiPlay). Раздаются через GitHub Pages.

- `tiles/<z>/<строка>/<столбец>.webp` и `tiles/manifest.json` — список существующих тайлов
- `popups/<id>.webp` — картинки из окон меток (id — первые 12 символов UUID оригинала)
